# 智能交易（aitrader）

面向飞牛 fnOS 的多智能体交易分析工具：技术面、新闻情绪、基本面三位分析师并行给出报告，多空研究员辩论，交易员输出方向、置信度与目标仓位。

**当前版本仅模拟盘**，不接真实资金，也不会向交易所发送订单。

默认端口 **8906**，打包为 `.fpk`。

## 功能

- **多智能体分析**：技术 / 新闻情绪 / 基本面并行，随后多空辩论与交易员决策
- **规则推理兜底**：未配置模型时用内置规则离线运行
- **可选大模型**：填入任意 OpenAI 兼容接口后由模型参与判断
- **信号广场**：每条决策都是一个信号，支持一键跟单到模拟盘
- **回测评分**：按历史价格统计信号命中率
- **自主交易**：达到置信度阈值自动在模拟盘执行，可一键停机
- **行情支持**：币安 / OKX / Bitget / A 股
- **风控与日志**：仓位上限、单日次数限制、运行日志

## 安装

1. 下载 `aitrader-1.1.0-x86.fpk`
2. 飞牛应用中心 → 手动安装
3. 打开「智能交易」，可选配置模型接口后发起分析

## 使用

| 模块 | 说明 |
| --- | --- |
| 发起分析 | 选择标的与周期，生成分析师报告与交易员决策 |
| 信号广场 | 查看历史信号与命中情况，一键跟单 |
| 行情 | 数字货币与 A 股行情展示 |
| 成交记录 | 模拟盘成交明细 |
| 运行与自主交易 | 开启/关闭自主交易、设置置信度阈值 |
| 模型（可选） | 配置 OpenAI 兼容接口 |
| 风控 | 仓位与频率限制 |

## 构建

```bash
./build/build.sh x86
```

依赖：Go 1.24+（仅标准库）。产物：`dist/aitrader-<version>-x86.fpk`。
